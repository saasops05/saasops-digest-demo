Support triage — mail/Slack → GitHub draft → Slack approve

This is a walkthrough of one sample run: a customer bug report arrives by email, gets classified by simple rules, is written up as a GitHub issue draft, and is posted to Slack for a person to approve. Everything below comes from a fixture file. No live mailbox, Slack, or GitHub accounts were used, and nothing gets filed until someone approves it.

  • Fixture: fixtures/bug-email.json
  • Deterministic rules, no LLM
  • Dry-run: nothing posted or filed
  • Human approval required
